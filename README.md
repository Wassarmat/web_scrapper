## 📖 О проекте

**Web Scrapper** — это учебный проект, созданный для изучения многопоточного программирования на C++ с использованием фреймворка Qt. Программа сканирует веб-страницы, извлекает из них информацию (заголовки, текст, ссылки) и сохранять результаты в формате JSON.

### Основные возможности

*   **Многопоточное сканирование**: Использование потоков для ускорения работы.
*   **Графический интерфейс**: Простой функционал, ничего лишнего.
*   **Ограничение глубины**: Контроль количества обрабатываемых страниц.

## 🚀 Начало работы

Эти инструкции помогут вам установить и запустить проект на вашем компьютере для разработки и тестирования.

### 📋 Предварительные требования

Для сборки и запуска проекта вам понадобится:

*   Компилятор C++ с поддержкой стандарта C++17 (например, GCC 7+ или Clang 5+).
*   [CMake](https://cmake.org/) (версия 3.16 или выше).
*   [Qt](https://www.qt.io/) (версия 6.0 или выше).
*   Библиотека [libcurl](https://curl.se/libcurl/).

Например, для Ubuntu/Debian их можно установить так:
```sh
sudo apt update
sudo apt install build-essential cmake qt6-base-dev libcurl4-openssl-dev
```
